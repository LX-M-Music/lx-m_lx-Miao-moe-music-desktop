# 低功耗模式

入口：**设置 → 高级 → 低功耗模式**。默认关闭，开启和关闭均立即生效，无需重启。开关会保存；其他显示设置保留原值，关闭低功耗模式后按这些设置恢复。

## 降低或暂停的项目

| 项目 | 普通模式 | 低功耗模式及可见影响 |
| --- | --- | --- |
| 动态背景 | 按原设置显示静态、轻柔或完整流动效果 | 使用静态封面色彩，暂停背景流动和切歌时的背景渐变；切歌、主题变化和窗口尺寸变化仍会更新背景 |
| 背景渲染资源 | WebGL 画布、纹理、程序及帧缓冲；静止时可额外生成 PNG 快照 | 切换时释放原 WebGL 资源，改用最长边不超过 384 像素的小尺寸 2D 画布；按需绘制，不保留额外 PNG 快照。封面本身的显示清晰度不降低 |
| 统一界面动画 | 根据平滑动画及动画速率设置播放过渡 | 暂停统一动画时钟控制的页面、面板、弹窗、播放详情展开/收起、封面飞入以及颜色/缩放过渡；功能直接完成切换 |
| 歌词的视觉过渡 | 当前句放大、颜色过渡、自动居中滚动带动画 | 当前句高亮、放大、居中及翻译/罗马音仍可用，主界面的放大和自动滚动直接到位；歌词计时、逐字进度及手动滚动/跳转不降频 |
| 音频可视化 | 跟随屏幕刷新率，画布上限 800 万像素、DPR 上限 2 | 配套插件 1.2.1 绘制不超过 30 帧/秒，画布上限约 100 万像素、DPR 上限 1；频谱、波浪和径向样式仍保留。主播放页、预览和迷你/桌面歌词窗口均遵循此策略 |
| 径向频谱内部画布 | 边长上限 1400 像素 | 边长上限 640 像素；音频 FFT 精度和音频处理不降低 |
| 隐藏的迷你/桌面歌词窗口 | 可继续请求频谱数据 | 在低功耗模式下暂停隐藏窗口的频谱请求和持续重绘；显示后恢复。歌词及播放控制保留 |
| 共享封面内存缓存 | 预算 32 MiB、256 项 | 预算 8 MiB、48 项；优先淘汰闲置图片。正在显示或仍被引用的封面不撤销，因此大量同时显示的封面可暂时超过预算 |
| 背景封面缓存 | 保留最近 6 张 256×256 的背景封面 | 保留最近 1 张；减少解码图像和预览数据的长期驻留 |
| 封面地址/显示地址缓存 | 未设置条数上限 | 两个缓存分别限制为 64 项；丢弃的是内存副本，磁盘中的封面和地址仍保留，之后按需读取 |
| Chromium 闲置网页资源 | 由浏览器自行保留 | 开启后等待界面释放旧资源，再释放一次不再使用的网页内存缓存；不定时反复清空，不清理磁盘缓存，不强制 GC |

如果原来关闭了动态背景或音频可视化，低功耗模式不会开启它们。按钮随背景配色、文字对比度、播放页黑色遮罩及字体大小设置继续有效。

## 保留的功能

音频播放、音质选择（含 Master）、音效/EQ、响度归一、变速、无缝切歌、淡入淡出、下一首预加载、歌词同步、逐字歌词、翻译和罗马音、迷你播放器及桌面歌词继续按原设置工作。

搜索、歌单、排行榜、下载、设备同步/WebDAV、开放 API、快捷键、更新和插件启用状态均保留。歌曲、歌词、歌单、下载文件、磁盘封面缓存及插件偏好不删除。低功耗开关不通过 WebDAV 自动覆盖其他设备。

音频可视化的降帧需要配套插件 **1.2.1**；本次已生成源码 ZIP 和编译后的 LXPlugin 包并更新本地商店目录。旧版插件和其他第三方插件仍保持自己的绘制行为，不会被强行关闭。新版插件在没有低功耗接口的旧版软件中保持普通绘制行为。

## 验证和测量

用隔离的临时配置验证即时切换、开关保存和重启恢复、原偏好保持、WebGL 程序释放/恢复、静态背景及主题配色、真实音频进度、歌词跟随，以及主播放页和桌面歌词窗口的可视化。4K 窗口下检查可视化画布限额。检查活跃封面的 URL 和原尺寸保持不变，以及被淘汰封面断网后仍能从磁盘重新读取。

内存场景：顺序浏览 40 张不同的 640×640 封面，保留当前播放封面的引用，关闭动态背景；缓存数值来自软件缓存管理界面，显示值保留两位小数。渲染进程私有内存取测试中 GC 后三次采样的中位数；软件本身不会强制 GC。

两个运行版本的一次记录（均在当前 Windows 上运行）：

| 指标 | 普通模式 | 低功耗模式 |
| --- | ---: | ---: |
| 共享封面缓存（含解码估算） | 31.25 MiB | 7.81 MiB |
| 普通版 Electron 43.7.3 渲染进程私有内存 | 142.56 MiB | 130.73 MiB |
| 兼容版 Electron 22.3.27 渲染进程私有内存 | 86.51 MiB | 79.99 MiB |

六个 TypeScript 项目和针对性 ESLint 检查通过；52 项单元检查、普通版 60 项运行/界面检查及兼容版 27 项运行/界面检查通过。普通版隔离构建、兼容版四个构建目标和 Node 16 运行包审计通过。兼容版运行检查使用当前 Windows，未测试真实 Windows 7 设备。

缓存管理的数值不是整个软件的内存占用；渲染进程数值也不包括主进程和 GPU 进程。减少缓存预算不保证操作系统立即收回相同大小的内存。实际收益随封面数量、插件、显示尺寸和硬件变化，不能把缓存下降约 75% 当作整个软件下降 75%。

原始记录和界面截图位于 `output/playwright/low-power/`，其中 `memory-43.7.3.json`、`memory-22.3.27.json` 分别记录普通版和兼容版验证时的测量。
