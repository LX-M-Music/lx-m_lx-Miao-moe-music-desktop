# LX Music 2.12.5 / 2.12.6 合入记录

本次按官方 `v2.12.4..v2.12.6` 的源码差异合入两个版本的七项公告内容，并与旁边的 `lx-music-desktop-2.12.6` 源码核对。LX-M 保持自己的产品名称、版本号和发布配置。

官方来源：[2.12.5](https://github.com/lyswhut/lx-music-desktop/releases/tag/v2.12.5)、[2.12.6](https://github.com/lyswhut/lx-music-desktop/releases/tag/v2.12.6)。

| 版本与更新项 | 上游提交 | LX-M 处理 |
| --- | --- | --- |
| 2.12.5：主题颜色选择器默认颜色 | `378174c2` | 主版本与 Win7 锁文件均精确固定 `@simonwep/pickr` 1.9.1；检查已保存主题再次编辑与重启后的初始色。 |
| 2.12.5：MP3 歌曲数据嵌入失败 | `378174c2` | 保留已有的临时副本、等待标签写入完成后原子替换方案；修复 Win7 worker 的浏览器 URL 与 Node HTTP URL 类不兼容问题；使用生产下载 worker 实际嵌入并读取标题、歌手、专辑、封面与歌词，确认当前 webpack 的结果。 |
| 2.12.6：QQ 推荐歌单 | `bb8d0727` | 新增 `GetRecommendWhole` 公共推荐及分类接口调整；显示为“广场推荐”，保留 LX-M Cookie 个人推荐和歌单详情备用接口；迁移旧最热排序值 5 至 3，保留请求取消。 |
| 2.12.6：禁用透明时窗口边框 | `e20b2844` | 按系统应用边框：Linux 普通窗口细边框、Windows 10 顶部细线、Windows 11 原生外观；全屏移除内容边框。Windows 11 依据 NT 10.0 的构建号识别。 |
| 2.12.6：酷狗部分歌单缺歌 | `e9bc6a57` | 携带 `global_collection_id` 与 `chain` 使用新接口，按 50 首完整获取全部分页；修复分享跳转的 GCID 提取并保留旧接口回退。 |
| 2.12.6：Win7 无法启动 | `96fd3306`、`7c78e557` | LX-M 已有独立 Electron 22.3.27 / better-sqlite3 9.6.0、ABI 110 编译及成品审计流程；继续使用该方案，避免把上游的其他 ABI 原生库覆盖进来。 |
| 2.12.6：禁用透明时 F11 无法全屏 | `e20b2844` | 在进入全屏前恢复可调整尺寸状态，全屏时保持该平台所需状态；退出时恢复 LX-M 的最大化或普通窗口缩放约束。 |

上游额外添加的阻塞式旧版 Windows 提示弹窗不属于这七项公告内容，未引入 LX-M。
